# Miyigbena Abidemi Dorcas — Portfolio

A responsive professional portfolio built with Next.js, TypeScript and Tailwind CSS. Its career information is based on the supplied DOCX CV; the original DOCX and the supplied portrait are included in `public/`.

## Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Set `NEXT_PUBLIC_SITE_URL` to the deployed site’s origin to include the portrait in Open Graph and Twitter share metadata. Without it, the page still publishes its title and description without emitting a localhost share-image URL.
